# Il Capriccio — Menú digital (ES/EN)
Abrir `index.html` con Live Server (puerto 5501) o con doble clic.
- `data/menu.js`: platos, precios y traducciones. `"r":1` = aparece en «Te recomendamos».
- `img/cat/`: fotos de categorías (ver LEEME.txt).
- Cambiar idioma: botón con globo (arriba a la derecha); se recuerda la elección.
